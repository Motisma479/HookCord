# HookCord
## ⭐ About the Project

This project is a small tool to talk trough a discord webhook with some twikable parameter like the webhook Profile picture or the webhook user name.

The tool is written in [![C++](https://img.shields.io/badge/v20-blue?style=flat&logo=C%2B%2B&label=C%2B%2B)](https://isocpp.org/) an is compilled using [![CMake](https://img.shields.io/badge/v3.10-blue?style=flat&logo=CMake&label=CMake)](https://cmake.org/).

## 📚 External library :

|Feature|Library|
|:-:|:-:|
|Window|[GLFW](https://github.com/glfw/glfw)|
|GUI|[Dear ImGui](https://github.com/ocornut/imgui)|
|OpenGL loader|[glad](https://github.com/Dav1dde/glad)|
|JSON|[JSON_CPP](https://github.com/Motisma479/JSON_CPP)|
|Requests|[curl](https://github.com/curl/curl)|

## 🔧 Getting the code

To get the project correctly use the following command:

git clone --recursive https://github.com/Motisma479/HookCord.git
